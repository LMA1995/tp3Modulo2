# 🧪 Trabajo Práctico JavaScript

## 📌 Descripción

Este proyecto consiste en la resolución de distintos ejercicios prácticos utilizando **JavaScript** y **HTML**, enfocados en la manipulación de datos, estructuras de control, arrays y el uso del DOM.

El objetivo principal es reforzar conceptos básicos de programación mediante la interacción con el usuario y la visualización de resultados en pantalla.

---

## 🚀 Tecnologías utilizadas

* HTML5
* JavaScript (ES6)

---

## 📚 Contenidos trabajados

* Variables y tipos de datos
* Estructuras condicionales
* Bucles (`for`, `do...while`)
* Arrays
* Métodos de arrays (`push`, `splice`, etc.)
* Manipulación del DOM (`innerHTML`)
* Funciones
* Generación de números aleatorios (`Math.random`)

---

## 🧩 Ejercicios incluidos

### 1. 📅 Listado de meses

* Creación de un array con los 12 meses
* Visualización en formato lista HTML

---

### 2. 🏙️ Gestión de ciudades

* Ingreso de ciudades mediante `prompt`
* Almacenamiento en un array
* Visualización de:

  * Longitud del arreglo
  * Primer, tercer y último elemento
  * Segunda posición
* Modificaciones:

  * Agregar "París"
  * Reemplazar un elemento por "Barcelona"
* Renderizado en pantalla con listas HTML

---

### 3. 🎲 Simulación de dados

* Generación de números aleatorios entre 1 y 6
* Simulación de 50 lanzamientos de dos dados
* Cálculo de la suma
* Conteo de frecuencia de resultados
* Visualización de ocurrencias

---

## 💡 Aprendizajes clave

* Uso correcto de índices en arrays
* Diferencia entre almacenar datos y contar ocurrencias
* Importancia del orden de ejecución
* Buenas prácticas en manipulación del DOM
* Evitar el uso de `document.writeln` en favor de `innerHTML`

---

## ▶️ Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio
2. Abrir el archivo `index.html` en el navegador
3. Interactuar con los prompts para ejecutar los ejercicios

---

## 📌 Notas

* El proyecto está orientado a la práctica y aprendizaje
* No utiliza frameworks ni librerías externas
* Se recomienda ejecutarlo en un navegador moderno
